# Иконки источников для значка входящих (M-MAIL)

Логотипы сервисов, из которых роутер раскладывает входящие по проектам.
Собраны из официальных фавиконов и пересобраны в `.ico` с кадрами 16 и 32
(панель рисует значок в 14px, поэтому единственный крупный кадр мылился бы).

| Файл | Источник |
|---|---|
| `mailru.ico` | mail.ru |
| `yandex.ico` | mail.yandex.ru |
| `gmail.ico` | Gmail (gstatic) |
| `telegram.ico` | telegram.org |
| `max.ico` | max.ru |

## Как подключить

Скопировать в `%APPDATA%\claudebar\mail-icons\` — панель подхватит при следующем запуске:

```powershell
Copy-Item assets\mail-icons\*.ico "$env:APPDATA\claudebar\mail-icons\" -Force
```

Новый источник у роутера (ключ из поля `sources=`) требует только нового файла
`<ключ>.ico` в той же папке — код менять не нужно. Пока файла нет, панель рисует
марку фирменного цвета, так что источники всё равно различимы.

Имя файла = ключ источника, и панель принимает только `[a-z0-9_-]`: ключ приходит
из файла внешнего роутера, поэтому путь в нём не допускается.

Логотипы принадлежат своим правообладателям и лежат здесь только для того, чтобы
значок был узнаваемым; на лицензию самого ClaudeBar (MIT) это не распространяется.
